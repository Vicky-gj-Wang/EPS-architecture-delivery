L0 全景：输入 -> 决策 -> 执行 -> 反馈 -> 安全 -> 诊断

这是一条面向功能的主链路。状态机决定当前运行模式，三环控制负责转矩与动态性能，保护链路兜底安全，通信诊断负责外部可观测和参数闭环。

状态机协作
运行模式管理
目标：定义系统在自检、初始化、运行、故障、休眠等模式下的合法迁移。
输入：事件触发、故障标志、唤醒/休眠请求。
输出：任务使能、控制链激活状态、保护动作。
起手改动：先查迁移矩阵，再查事件源和动作函数。
打开状态机专题页
三环电机控制
性能与跟踪
目标：在约束内实现转矩响应、稳态精度和动态平顺。
输入：目标扭矩/角度、估算速度、电流采样值。
输出：d/q 轴电流指令、SVPWM 占空比。
起手改动：先定位环路边界和周期，再动 PI 参数或前馈项。
验证重点：采样相位一致性、限幅顺序、抗积分饱和。
打开三环控制专题页
安全保护链
安全兜底
目标：过流/过压/过温/传感器异常下快速进入可控安全状态。
输入：采样阈值比较、状态机阶段、故障计数器。
输出：降扭矩、关 PWM、锁故障、故障清除策略。
起手改动：先看故障仲裁，再看状态机中的故障出口。
风险：误触发会导致可驾性问题，漏触发会导致安全风险。
打开安全保护专题页
调度与时序
实时性骨架
目标：保证中断和任务在周期与优先级上满足控制闭环时限。
输入：定时器节拍、ADC/EVENT 中断、任务触发表。
输出：任务执行顺序、执行窗口、丢帧/延迟统计。
起手改动：先看高优先级 ISR，再看周期任务调用链。
验证重点：最坏执行时间、抖动、竞态与共享资源保护。
打开调度时序专题页
通信与标定
外部接口
目标：支持 UDS 诊断、XCP 标定与参数在线/离线一致性。
输入：CAN 报文、会话状态、标定写入请求。
输出：参数生效、掉电持久化、诊断响应。
起手改动：先界定参数生命周期，再改映射与持久化流程。
验证重点：会话权限、写保护、掉电恢复一致性。
打开通信诊断专题页
诊断与可观测性
问题定位
目标：让问题可复现、可定位、可量化评估。
输入：故障事件、运行变量快照、状态迁移日志。
输出：DTC、诊断帧、调试观测点。
起手改动：优先补可观测点，再改控制/保护逻辑。
建议：每个新增策略都带一组可验证观测变量。
